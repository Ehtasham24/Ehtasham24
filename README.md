## 🍒 Featured Project — Cherry Spot

<a href="https://github.com/Ehtasham24/cherrySpot-releases/releases/latest"><img src="https://img.shields.io/github/downloads/Ehtasham24/cherrySpot-releases/total?style=for-the-badge&label=Downloads&color=e11d48" alt="Downloads"/></a>
<a href="https://github.com/Ehtasham24/cherrySpot-releases/releases/latest"><img src="https://img.shields.io/github/v/release/Ehtasham24/cherrySpot-releases?style=for-the-badge&label=Latest&color=30363D" alt="Latest release"/></a>
<img src="https://img.shields.io/badge/Windows-0078D6?style=for-the-badge&logo=windows&logoColor=white" alt="Windows"/>
<img src="https://img.shields.io/badge/Linux-FCC624?style=for-the-badge&logo=linux&logoColor=black" alt="Linux"/>

A desktop app that turns Git cherry-picking from a chore into a few clicks.

| | |
|:---|:---|
| **The problem** | Finding the right commits means scrolling through long logs and copying hashes, and conflicts get untangled by hand. Slow and easy to get wrong. |
| **The solution** | Search commits, pick them across branches, and resolve conflicts with a built-in 3-way merge tool and reflog explorer. |
| **The result** | **1,000+ downloads** across 40+ releases, each one shaped by user feedback. Signed installers with auto-updates for Windows and Linux. |
| **Built with** | Rust · Tauri · TypeScript |
